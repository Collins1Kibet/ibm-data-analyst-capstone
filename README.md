# IBM Data Analyst Capstone Project

## Project Overview
This project is part of the IBM Data Analyst Professional Certificate. It demonstrates an end-to-end data analysis workflow, covering data collection, cleaning, analysis, visualization, and dashboard development.
The goal of the project is to analyze job market trends, identify in-demand skills, and generate insights that can support data-driven decision-making.

---

## Tools & Technologies
- Python (Pandas, NumPy)
- Web Scraping (BeautifulSoup)
- APIs (Data Collection)
- Data Visualization (Matplotlib)
- IBM Cognos Analytics
- Looker Studio

---

## Project Workflow

### 1. Data Collection
- Extracted data using APIs  
- Collected additional data through web scraping  

### 2. Data Wrangling
- Handled missing values  
- Removed duplicate records  
- Standardized and normalized data  

### 3. Exploratory Data Analysis (EDA)
- Analyzed data distributions  
- Detected outliers  
- Identified relationships using correlation analysis  

### 4. Data Visualization
- Created visualizations including:
  - Bar charts  
  - Pie charts  
  - Scatter plots  
  - Line charts  

### 5. Dashboard Development
- Built an interactive dashboard using Looker Studio  
- Visualized key trends in job demand, salaries, and skills  

---

## Data Sources
The datasets used in this project were obtained through:
- API data collection  
- Web scraping  
- IBM-provided datasets  

The data includes job roles, required skills, salary information, and technology demand trends.

---

## Notebooks
The analysis is organized into structured notebooks covering:
- Data collection  
- Data cleaning and preparation  
- Exploratory data analysis  
- Data visualization  

---

## Key Insights
- Certain technologies show consistently higher demand across job postings  
- Salary trends vary significantly based on skill specialization  
- Data-related roles require a combination of technical and analytical skills  
- Emerging tools and technologies are gaining traction in the job market
